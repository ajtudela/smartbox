# Web API spec (moved)

The current wire record lives in the sibling `hass-smartbox` repository under
`docs/`:

- `docs/api-endpoints.md` — the endpoint index with consumer, status and last-confirmed build
- `docs/api-contract.md` — the full wire contract and evidence record

the canonical source. This file remains only as a pointer so older links do
not silently serve a stale, library-specific copy.
